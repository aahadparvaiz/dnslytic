Understanding DNS Records

New to DNS? Here is what each common record type means.

A
IPv4 Address

Connects a domain name to an IPv4 address so devices can find the server hosting it.

AAAA
IPv6 Address

Connects a domain name to an IPv6 address, the newer version of the Internet Protocol.

CAA
Certificate Authority

Specifies which Certificate Authorities are allowed to issue HTTPS certificates for a domain.

CNAME
Canonical Name

Points one domain or subdomain to another domain name.

MX
Mail Server

Tells email systems which servers are responsible for receiving email for the domain.

NS
Name Server

Shows the DNS servers responsible for managing DNS information for the domain.

TXT
Text Record

Stores text information commonly used for verification, SPF, security policies and other DNS-based configuration.

SOA
Start of Authority

Contains administrative and timing information about a domain's DNS zone.
